# 局部智能布线与手动调整

新建导线会按引脚朝向离开主体，再寻找正交通道，避让元件及自定义符号的主体范围。不同网络的平行线保持至少 10 个画布单位的间距，避免同一段导线完全重合。网络依据显式端点和同名节点判断，不依据当前 0/1 信号或颜色判断。

## 新建和移动

- 选择模式靠近引脚单击，或按 W 开始布线；空白处单击设置途经点。预览使用与提交相同的路由计算。
- 移动、旋转元件或改变接口布局后，释放鼠标时重排关联导线，以及被元件新位置挡住的其他导线。放置新元件挡住已有走线时也会触发局部调整。
- 未受影响的导线保持原路径。打开旧工程不自动整理整张图。
- 同网分支允许共享走线；不同网络可以交叉，竖线在交叉处留小断口，表示此处不连接。竖线本身仍保持电气连续，真实连接需要显式端点或节点。

## 调整已有导线

| 操作 | 方法 |
| --- | --- |
| 重排局部线路 | 选择导线，或选择元件以包含其关联导线；执行“工具 → 重排选中导线”，快捷键 `Ctrl+Shift+R`，右键菜单也可使用 |
| 手动挪动线段 | 单击选择导线，再拖动线段中部或小方块；水平段上下移动，竖直段左右移动，按 10 个画布单位吸附；端点保持不动 |
| 切换重叠候选 | 指向重叠处，`Alt+单击` 或 `Tab` 依次选择候选导线；`Shift+Tab` 反向切换。普通点击优先选距离最近的可见线段 |
| 在重叠线中选择分支目标 | 先切换选中目标导线，再按 W 在其上开始分支；明确选中的候选优先作为分支目标 |
| 取消调整 | 按 Esc；未完成布线、临时分支及当前拖动一并回退 |
| 撤销与重做 | `Ctrl+Z` / `Ctrl+Y`；一次线段拖动、一次重排或“放置元件并避让”各为一条历史记录 |

纯粹重排导线或拖动线段不会复位正在运行的仿真。移动元件等结构操作沿用编辑器的复位行为。手动形状会保存为普通折点；后续移动关联元件或再次执行重排时，会重新计算受影响线路，可在其后继续手动调整。

## 空间不足时

引脚被另一元件盖住、途经点位于主体内，或搜索范围内没有足够通道时，程序不会用穿过主体的路径冒充避让成功。新线不会提交；自动重排失败的已有线保留原路径，并在底部状态行提示。手动拖动遇到无可用通道的位置时，保留上次有效形状。移开重叠元件、调整途经点或重排附近其他导线后可重试。

正交搜索对规模设有边界，以免复杂工程阻塞界面；它用于局部交互布线，不会自动移动元件来腾出空间。

## 代码与验证

- `include/LogicRouting.h`、`src/LogicRouting.cpp`：网络分组、引脚出线方向、主体障碍、不同网络间距、正交路径搜索、局部重排及交叉位置。
- `src/LogicWireTools.cpp`：预览、候选切换、线段拖动、断口绘制、按需重排命令及 GUI 回归。
- `tests/routing_tests.cpp`：原始重合案例、移动后的局部修复、旋转和底边选择端、自定义外部引脚、途经点、手动线段、保存往返、网络不变及失败不修改模型。
- GUI 回归生成 `ROUTING-PASS.txt`，并输出 `routing-separated-inputs.png`、`routing-new-obstacle.png`、`routing-manual-segment.png`、`routing-new-wire.png` 和 `routing-crossing-gap.png`。
