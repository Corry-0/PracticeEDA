## 运行状态边界

查看实例、缩放、平移与层级返回不改变仿真时间、寄存器、RAM 或工程初值。嵌套 Input 接口由父层驱动，只读显示。内部 Button 可单独操作运行态。修改结构、参数、外观接口或初值需进入定义编辑，并暂停、复位根仿真。保存工程记录结构和初值，不隐含加入运行快照功能。
