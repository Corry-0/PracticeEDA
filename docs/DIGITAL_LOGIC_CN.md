# 数字逻辑编辑器：功能与验收说明

当前项目仅包含数字电路设计与仿真，启动后直接进入数字编辑器。

已增加工程师自定义元件（接口创建、独立保存、跨工程导入）及 KiCad/JSON 网表导出，操作和格式详见 [自定义元件与网表说明](CUSTOM_COMPONENTS_NETLIST_CN.md)。左侧原“子电路”分组现显示为“自定义元件 / 子电路”，兼容已有定义。

## 启动

启动 `build/Debug/PracticeEDA.exe` 或 `build/Release/PracticeEDA.exe`；分发包内双击 `PracticeEDA.exe` 或 `DigitalLogic.cmd`。命令行 `PracticeEDA.exe examples/half-adder.logic.json` 打开示例，`--logic` 参数仍兼容。

顶部提供带图标的文件/编辑/仿真工具栏，以及输入、输出、时钟、逻辑门、分线器和寄存器等常用元件快捷栏。左侧为七类元件树、子电路库和搜索框，右侧上方为“属性 / 值”两列表格，下方为实时连接诊断列表和详细提示。图标来自 wxWidgets samples 与内置数字符号，已嵌入可执行文件。

鼠标靠近引脚或连接节点时，显示向外扩散并淡出的绿色涟漪。提示使用与布线相同的最近端点判定，范围约为 9 个逻辑像素，缩放时保持屏幕大小；绿色表示可定位的连接端点，不表示信号一定为 1。离开端点、离开画布或拖动、平移、放置元件时停止动画。涟漪不改变仿真状态，也不出现在导出的电路 PNG 中。GUI 回归输出 `logic-pin-ripple.png` 供检查。

## 输入输出状态与连接检查

输入、输出主体缩小为 28×28，相比与门等逻辑元件更紧凑；输入为方形，输出为圆形。原有引脚坐标、工程模型及连线保持不变。主体边框与填充随实际信号变化：蓝色为 0，绿色为 1（总线为已知非零），黄色为 X 未知，灰色为 Z 高阻，红色为 E 冲突或错误。多位引脚在主体中显示 BUS，信号值在下方显示，较长的混合状态可在属性表格的“当前信号”中查看。选中轮廓不覆盖状态色，放置预览为中性灰。

右下方不再显示固定操作说明，改为随连线和仿真更新的连接检查。错误、警告、提示分别计数；列表包括位宽不匹配、驱动冲突、悬空/高阻、未知信号及振荡。单击查看详情和检查建议，双击定位元件或导线；问题修复后提示自动消失。画布网格点颜色加深，PNG 导出仍不包含网格。

## 十项功能对照

| 要求 | 实现与检查方式 |
| --- | --- |
| 1. 画布编辑与元件拖拽 | 库单击后放置、库拖入画布、对象拖动、Shift 多选、框选、箭头微移、网格吸附、缩放和平移；连接随稳定引脚 ID 移动 |
| 2. 门、输入输出、时钟、触发器 | 七类库、44 种元件/注释；门和时序元件均有真实求值行为，详见下表 |
| 3. 导线、总线、节点 | 1–32 位总线，分线/合线器，折线布线、分支自动拆线、显式节点、同名节点连接；位宽不匹配报错 |
| 4. 事件驱动仿真 | 按逻辑时间排序的事件队列；同一时刻批量求值后传播；只调度变化网络的下游；预算限制及振荡诊断 |
| 5. 子电路 | 新建定义、输入/输出接口、完整电路封装、放置实例、双击进入、命名与删除；层次展平后每个实例拥有独立状态；拒绝递归引用 |
| 6. 项目文件 | 版本化 `.logic.json`，保存全部子电路和存储器初值，原子写入，中文路径，未保存退出提示；载入前校验 |
| 7. 真值表和表达式 | 穷举组合电路真值表，包含总线各位和组合子电路；生成标准与或式；输入表达式求真值表；导出 CSV |
| 8. 图片导出 | 导出完整电路 PNG，自动计算范围，包含信号颜色和标签，清除选择框与网格；不局限屏幕区域 |
| 9. 撤销/重做、复制/粘贴 | 100 步工程快照，Ctrl+Z/Y；系统剪贴板 Ctrl+C/X/V；内部连线随元件复制，单独复制导线时生成自由端点；子电路定义随跨工程粘贴导入 |
| 10. 错误与调试 | X/Z/E 区分、总线位宽错误、冲突、悬空与振荡诊断；画布高亮、诊断列表双击定位；单步、复位、时钟运行暂停、最近 2000 条事件追踪 |

以上为教学用途的可运行实现，不代表完整复刻 外部电路 的所有器件与属性。

## 推荐操作流程

1. **文件 → 打开半加器示例**。双击 A、B 输入切换 0/1，观察 Sum 与 Carry。
2. **分析 → 当前电路真值表与表达式**，应得到 Sum = (!A & B) | (A & !B)，Carry = (A & B)。文件菜单可导出最近的分析 CSV。
3. 选择库中的门后点击画布放置；按 S 回到选择。按 W 开始连线，点击端口开始/结束，空白处添加拐点，双击空白结束到自由节点。Esc 取消整条未完成连线，包括临时分支节点。
4. 点击已有导线建立分支。两条线的交叉不自动相连；必须使用明确的节点/端点。节点名称相同会在当前电路内连接，子电路实例之间不会因内部标签同名而短接。
5. 选中元件，在右侧属性表格双击“值”列或按 F2 编辑，回车或离开单元格后直接应用，无需点击应用按钮；可编辑名称、位宽、输入/初始值和 RAM/ROM 初值。只显示当前对象适用的属性，类型、ID、当前信号为只读；数值支持十进制和 `0x`。非法值回退并在诊断详情中说明原因。改变输入值保留寄存器/RAM 运行状态；结构和属性编辑会复位仿真。仅选择对象不会复位。
6. F8 翻转时钟半周期。F5 以 500 ms 半周期运行/暂停。复位后队列停在初始时刻，F7 每次推进一个事件时间批次；单步传播不会主动翻转时钟。
7. **项目 → 新建子电路**，用 Input、Output 元件定义接口；通过左上角下拉框切回 main，在左侧“子电路”放置实例。双击实例进入定义；编辑定义影响全部实例。接口端口使用稳定 ID，重命名引脚不会断线。
8. **项目 → 封装当前电路**会复制当前电路为一个新定义。返回库中放置即可调用。此操作不自动替换原电路。
9. Ctrl+S 保存工程，Ctrl+Z/Y 撤销/重做；框选部分元件后 Ctrl+C/V 复制。跨工程粘贴会为依赖的子电路重命名并重新分配 ID，避免覆盖原定义。

示例包括 `half-adder.logic.json`、`bus-register.logic.json` 和 `hierarchical-adder.logic.json`。

## 仿真语义与边界

- 使用整数逻辑时间，元件传播延迟为 1；这不是物理电路的纳秒时序模型。一个时间批次中的节点读取旧网络值，随后同时发布新输出，避免元件排列顺序改变触发行为。
- 0/1 为已知信号，X 为未知，Z 为高阻，E 为冲突/非法运算。总线逐位解析；两个不同的已知驱动值产生 E。悬空输入会被提示；AND 的已知 0、OR 的已知 1 可决定输出。
- 时钟固定 1 位。其他数据通道支持 1–32 位。二输入逻辑门按位运算；分线器按 B0 为最低位拆分，合线器反向组合；零扩展器将单比特扩展到 N 位。
- 算术为无符号整数，结果截断到设定宽度；Add.C 为进位，Subtract.C 为借位；Compare 输出 LT/EQ/GT；除零为 E；移位数量由 B 提供，超出 31 返回 0。
- 存储元件仅在明确的 0→1 上升沿采样，CLK 从 X/Z 变 1 不视为明确上升沿。D/T/JK/SR 可按位工作；SR 同时置位与复位产生 E；Counter.EN 为高时计数；ShiftRegister 从低位移入 D。
- RAM/ROM 固定 8 位地址、256 字，数据宽度可调。RAM 上升沿在 WE=1 时写入、异步读取，ROM 只读。属性内支持空格分隔的初值；工程保存的是初值，不是运行中的 RAM 快照。
- 每次 settle 最多处理 10000 个事件时间批次；超过后停止并报告振荡或传播过长，需复位或编辑修复。显示最近 2000 条输出变化。
- 真值表限组合电路，输入总位数≤10、输出总位数≤128，至少一个 Output。遇到时序元件、反馈不收敛或未知输出会明确拒绝；不把它们伪装成确定结果。分析不会修改当前仿真状态。
- 输出表达式是标准与或式，未做布尔最小化。独立表达式输入支持英文/下划线变量名、0/1、!/~、&/*、^、|/+、括号；优先级为非、与、异或、或。
- 保存使用自有 `.logic.json`；可[受限导入 外部电路 2.7 `.circ`](CIRC_IMPORT_CN.md)，不支持 JAR 库、键盘/TTY、LED 矩阵、晶体管开关模型或专业 HDL 仿真。旧 `.eda.json` 工程不属于数字工程格式，打开时会提示格式不支持。
- 数字工程需显式保存；尚未提供自动恢复和运行状态断点持久化。

## 源码与验证

`include/Digital.h` / `src/Digital.cpp`：模型、元件目录、校验、项目/剪贴板、历史、分层网络、事件仿真、真值表、表达式解析。

`include/DigitalEditor.h` / `src/DigitalEditor.cpp`：数字窗口、分类树、属性、画布交互、诊断、导出及 GUI 集成检查。

`tests/digital_tests.cpp`：门真值表、总线、32 位运算、驱动冲突、三态、时钟沿、存储器、子电路隔离、粘贴 ID 重映射、命名节点、格式拒绝、队列和振荡回归。

`include/LogicSupport.h` / `src/LogicSupport.cpp` 提供独立几何、导线类型和原子文件读写。`src/LogicIcons.cpp` 按类型名提供工具栏图标；`include/LogicSymbols.h` / `src/LogicSymbols.cpp` 绘制画布、放置预览及导出的电路符号，来源详见 `resources/ICONS.md`。

执行 `scripts/build.ps1 -Configuration Debug -GuiTest` 或 `scripts/build.ps1 -Configuration Release -GuiTest -Package`，构建、运行数字测试和 GUI 检查。分别输出 `build/qa-debug/`、`build/qa-release/`，成功标志为 `LOGIC-PASS.txt`。检查启动、全部图标映射、快捷栏、拖动、连接、撤销、剪贴板、保存加载、仿真与导出。

GUI 检查还导出 `logic-symbols.png`（全部元件与子电路）、`logic-symbol-previews.png`（放置预览）、`logic-symbol-states.png`（选中、未知、高阻、错误状态）和 `logic-inverter.png`（输入—非门—输出）。检查所有端口被绘制、绘图不修改电路数据，以及连接命中位置与原有模型一致。
