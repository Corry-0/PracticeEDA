# 数字逻辑编辑器：功能与验收说明

当前 0.5 版本以数字电路设计与仿真为主，启动后直接进入数字编辑器。功能与左侧工作区布局参照本地 Logisim 2.7.1。

已增加工程师自定义元件（接口创建、独立保存、跨工程导入）及 KiCad/JSON 网表导出，操作和格式详见 [自定义元件与网表说明](CUSTOM_COMPONENTS_NETLIST_CN.md)。左侧原“子电路”分组现显示为“自定义元件 / 子电路”，兼容已有定义。

## 启动

启动 `build/Debug/PracticeEDA.exe` 或 `build/Release/PracticeEDA.exe`；分发包内双击 `PracticeEDA.exe` 或 `DigitalLogic.cmd`。命令行 `PracticeEDA.exe examples/half-adder.logic.json` 打开示例，`--logic` 参数仍兼容。

顶部为单行工具栏，从左到右依次为新建/打开/保存、导入/导出下拉按钮、选择/导线、输入/输出及基础逻辑门（非门、缓冲、与门、或门、异或、与非、或非、同或），各组用分隔线区分。“文件 → 导入”集中提供 `.circ`、自定义元件和真值表 CSV；“文件 → 导出”集中提供完整/批量 PNG、最近分析 CSV、逻辑网表 JSON、KiCad PCB 和自定义元件，工具栏下拉按钮提供相同入口。逻辑网表使用 `.json`，KiCad PCB 使用 `.kicad_pcb` 并自动生成配套 `.net` 和引脚映射文件。编辑、仿真和分析操作可通过顶部菜单及对应快捷键使用，其他元件可从左侧完整元件库放置。左侧依次为子电路选择与增删按钮、紧凑实例层次、搜索、元件库及“属性 / 值”两列表格；拖动分隔条可调整库与属性区高度。画布上方保留紧凑实例导航。图标来自 wxWidgets samples 与内置数字符号，已嵌入可执行文件。

鼠标靠近引脚或连接节点时，显示向外扩散并淡出的绿色涟漪。提示使用与布线相同的最近端点判定，范围约为 9 个逻辑像素，缩放时保持屏幕大小；绿色表示可定位的连接端点，不表示信号一定为 1。选择模式下点击附近引脚即可开始连线，空白处单击添加拐点，点击另一端子完成后继续保持选择模式；点击元件中心仍可选择、拖动，Shift 单击保留多选操作。离开端点、离开画布或拖动、平移、放置元件时停止动画。涟漪不改变仿真状态，也不出现在导出的电路 PNG 中。GUI 回归输出 `logic-pin-ripple.png` 供检查。

新线使用局部智能避让，按引脚方向出线，绕开元件主体，并与不同网络的平行走线保持间距。移动元件释放鼠标时，以及新放元件挡住已有导线时，只重排受影响线路。旧工程打开时不自动改变走线路径；可选中导线或元件，按 `Ctrl+Shift+R` 主动重排。选中导线后拖动中段或小方块可调整线段；重叠处用 `Alt+单击` 或 `Tab` 切换候选。不同网络交叉用竖线断口表示不连接；同网显式分支保持连通。详见 [布线说明](ROUTING_CN.md)。

## 输入输出状态与连接检查

输入、输出主体为 28×28，相比与门等逻辑元件更紧凑；输入为方形，输出为圆形。端子直接位于主体左右边框 ±14 处，移除外伸引线。全部内置元件也采用边框端子：逻辑门沿轮廓连接，MUX/DEMUX 的选择端在底边，功能块端子名称写在内部。旧工程的端口 ID、位宽及连线折点保留，导线端点自动跟随新轮廓，布局可能与旧版略有区别；手动自定义的外观和接口坐标仍按工程定义显示。主体边框与填充随实际信号变化：蓝色为 0，绿色为 1（总线为已知非零），黄色为 X 未知，灰色为 Z 高阻，红色为 E 冲突或错误。多位引脚在主体中显示 BUS，信号值在下方显示，较长的混合状态可在属性表格的“当前信号”中查看。选中轮廓不覆盖状态色，放置预览为中性灰。

ERC 不占用固定状态栏或侧面板，也不显示聚合气泡和迷你地图热点。错误对象显示红色，并在外围显示红色圆形叉号；警告对象显示黄色，并在外围显示黄色三角感叹号。每个对象只显示一枚 18 DIP 的图标；同一对象存在多条问题时使用最高严重级别，不把相邻对象的问题合并。图标自动避让元件主体、标签、实时值、引脚、导线和其他图标；视口内空间不足时省略图标，颜色与悬停详情继续可用。悬停图标或对象可查看规则、严重级别、涉及对象和修复建议。

点击图标可打开独立、非模态的问题列表，优先列出该对象的全部问题；也可选择“工具 → 查看 ERC 问题”（`Ctrl+Shift+E`）打开完整列表。单击列表项自动缩放定位并选中相关元件或导线。关闭窗口后不占用画布空间，问题修复后颜色和图标自动更新。图标不会进入 PNG 导出，也不拦截放置元件、点击引脚及正在进行的连线。现有诊断包括位宽不匹配、信号冲突、高阻、未知状态及振荡，仍属于仿真连接诊断，尚未补全专业静态 ERC；具体缺口见 [自查报告](audits/2026-10-22-erc/自查报告.md)。

## 推荐操作流程

1. **文件 → 打开半加器示例**。双击 A、B 输入切换 0/1，观察 Sum 与 Carry。
2. **分析 → 当前电路真值表与表达式**，应得到 Sum = (!A & B) | (A & !B)，Carry = (A & B)。文件菜单可导出最近的分析 CSV。
3. 从工具栏或元件库选中元件后点击画布放置，或从库拖入；每次放置后自动回到选择模式，移动鼠标、点击空白不会继续复制元件。靠近引脚时单击即可连线，也可按 W 进入导线工具。点击端口开始/结束，空白处添加拐点，双击空白结束到自由节点。Esc 取消整条未完成连线，包括临时分支节点。
4. 点击已有导线建立分支。两条线的交叉不自动相连；必须使用明确的节点/端点。节点名称相同会在当前电路内连接，子电路实例之间不会因内部标签同名而短接。
5. 选中元件，在左侧元件库下方的属性表格双击“值”列或按 F2 编辑，回车或离开单元格后直接应用。只显示当前对象适用的属性：方向下拉、数据位宽、输入数、逐输入反相复选框、异或多输入行为、名称、输入/初始值或 RAM/ROM 初值；当前信号只读，内部类型与 ID 不再占用表格行。选中库中工具时可预设随后放置的参数；空白选择时显示电路名称与统计。数值支持十进制和 `0x`，非法值回退并在表格下方说明原因。改变输入值保留寄存器/RAM 运行状态；结构和属性编辑会复位仿真。仅选择对象或修改工具默认参数不会复位。
6. F8 推进一个基础时钟节拍，F5 运行/暂停；默认播放每 500 ms 推进一拍。各 Clock 依自身高/低时长决定是否翻转，缺省高低各一拍时等同旧版半周期。F7 每次推进一个传播事件时间批次，不主动翻转时钟。
7. 点击左侧子电路选择框旁的 **+**（`Ctrl+Shift+N`）新建子电路，用 Input、Output 定义接口；删除按钮（`Ctrl+Shift+Delete`）可撤销地删除当前未被引用的非主电路。运行实例视图禁用增删定义。在调用电路中放置实例，双击观察该实例内部；面包屑和“返回上级”只改变视图，不重建运行器。需要修改定义时选择“编辑当前电路定义（暂停并复位）”；修改影响全部实例。接口名称变化不改变稳定 ID。
8. **项目 → 封装当前电路**会复制当前电路为一个新定义。返回库中放置即可调用。此操作不自动替换原电路。
9. Ctrl+S 保存工程，Ctrl+Z/Y 撤销/重做；框选部分元件后 Ctrl+C/V 复制。跨工程粘贴会为依赖的子电路重命名并重新分配 ID，避免覆盖原定义。

示例包括 `half-adder.logic.json`、`bus-register.logic.json` 和 `hierarchical-adder.logic.json`。

## 实验案例

选择“案例 → 实验案例”，在列表中选择案例即可查看实验目的、操作步骤和预期结果。第一批包括半加器、全加器、8 位总线寄存器、4 位计数器、RAM 读写和层次化半加器。点击“打开案例副本”或双击列表项，在主画布中加载可编辑工程，同时显示可独立关闭、调整大小的说明窗口。

打开案例前仍会提示保存当前未保存工程；取消后保留当前工程。案例以未保存的新副本打开，Ctrl+S 会要求选择保存路径，不会直接覆盖 examples 中的模板。案例使用现有仿真操作：F7 推进传播事件，F8 推进基础时钟节拍，F5 运行/暂停。“仿真 → 复位”恢复当前工程的初值；需要恢复原始电路结构时重新打开对应案例。说明为参考步骤，尚无自动播放或自动评分。

案例文件随程序放在 examples 目录，从任意工作目录启动均可打开。新增案例时，将原生 .logic.json 文件加入 examples，在 src/ExperimentCases.cpp 的 experimentCases() 中登记名称、文件名和说明，并在 CMakeLists.txt 的 EDA_EXAMPLES 中登记以便构建和安装时带上文件。

案例专项界面验证可运行：`PracticeEDA.exe --smoke-test qa-experiments --experiment-cases-only`。该检查验证六个副本的加载、仿真、原文件保护、说明窗口和案例选择/取消，不执行其他模块的界面检查。

## 实例、内存与日志

运行时打开子电路看的是所点实例的实际输入、内部导线、寄存器和 RAM，而非重新运行的独立定义。可以连续进入多层；同一定义的两个实例状态不同，面包屑的实例路径也不同。运行实例视图保护结构编辑，内部 Input/Output 仍是父电路接口；需要改变其输入，应返回父电路操作输入源。内部按钮、键盘、摇杆则作用于当前实例。

选择 RAM/ROM 后，“仿真 → 编辑存储器初始内容”以每行 16 地址的十六进制表格编辑定义初值，确定后复位。可读写 `v2.0 raw` 连续 HEX，支持 `数量*字值` 和 `#` 注释，数量为十进制、数据为十六进制。运行内存窗口只读，可导出当前实例的二态内容；包含 X/Z/E 时拒绝导出为二态 HEX。它不等于保存工程的初值，也不提供整个仿真断点恢复。

“仿真 → 信号监测 / 连续 CSV 日志”选择运行根内任意层次的元件输出，CSV 每行包含传播时间、完整实例路径、引脚和值。只在变化时记录；导航不停止记录。再次打开菜单可停止并关闭文件。最近 2000 条事件只限制界面缓存，持续文件不受该条数限制。

键盘通过“键盘输入 / TTY 内容”注入 UTF-8 字节 FIFO，DATA 为当前首字节，AVAILABLE 表示非空；READ=1 的采样边沿弹出一个字节。TTY 在 EN=1 的边沿采样 DATA，支持换行、退格与清屏；双击或菜单查看当前实例文本。摇杆可设置 X/Y 数值；这是一种教学输入方式，不连接外部游戏手柄。

## 真值表、化简与生成

分析窗口的输入列固定，输出列可填 0、1、`-`。`-` 是设计时可任选结果的不关心项，不是仿真错误 X。化简采用 Quine–McCluskey 与有预算的覆盖搜索；最多四变量可显示按格雷码排列的卡诺图，选择圈组高亮对应格点。更多输入仍可化简，搜索耗尽时说明结果等价但未证明最少项；中间项过多会拒绝并建议拆分。

“自动生成门电路”生成新的命名子电路，选择与/或/非结构或仅 NAND。程序对生成电路重新仿真，并逐行核对原表的所有确定输出，成功后才导入工程，原电路保留。不关心行可以被选为 0 或 1。

CSV 表头以 `IN:`/`OUT:` 区分输入输出，例如 `"IN:A","IN:B","OUT:Y"`；也可用 `|` 或 `OUTPUTS` 分隔。输入为 0/1，输出可为 0/1/`-`。旧版未标分类的 CSV 需补充表头前缀。表必须列全每种输入组合，不能出现重复行。

## 仿真语义与边界

- 使用整数逻辑时间，元件传播延迟为 1；这不是物理电路的纳秒时序模型。一个时间批次中的节点读取旧网络值，随后同时发布新输出，避免元件排列顺序改变触发行为。
- 0/1 为已知信号，X 为未知，Z 为高阻，E 为冲突/非法运算。总线逐位解析；不同强驱动产生 E，强驱动覆盖弱上/下拉。晶体管/传输门动态双向联通真实网络，关断恢复独立网络；不提供模拟电压或晶体管物理参数。AND 的已知 0、OR 的已知 1 可决定输出。
- 时钟固定 1 位，其他数据通道支持 1–32 位。门按位计算；分线器/合线器可任意分组，组内首位为分支最低位；合线目标位禁止重复，遗漏位补零。扩展器输入宽度不得大于输出宽度。
- 算术为无符号整数，结果截断到设定宽度；Add.C 为进位，Subtract.C 为借位；Compare 输出 LT/EQ/GT；除零为 E；移位数量由 B 提供，超出 31 返回 0。
- 时序元件可选明确的上升/下降沿；X/Z 到已知值不视为有效边沿。异步 CLR 优先。D/T/JK/SR 可按位工作；SR 同时置位与复位产生 E；原生 Counter.EN 高时计数，LOAD 优先装载，到 counterMax 后回零；ShiftRegister 从低位移入 D。导入 Logisim Counter 时保留其 CT/LD 方向与装载组合语义。
- RAM/ROM 默认 8 位地址、256 字，可配置 1–16 位地址、1–32 位数据。RAM 在配置边沿且 WE=1 时写入、异步读取；ROM 只读。单个最大 65536 字，展开后全部实例最多 4194304 字；初值与运行内容分离。
- 每次 settle 最多处理 10000 个事件时间批次；超过后停止并报告振荡或传播过长，需复位或编辑修复。显示最近 2000 条输出变化。
- 真值表限组合电路，输入总位数≤10、输出总位数≤128，至少一个 Output。遇到时序元件、反馈不收敛或未知输出会明确拒绝；不把它们伪装成确定结果。分析不会修改当前仿真状态。
- 标准与或式与化简式均可查看。独立表达式支持英文/下划线变量名、0/1、!/~、&/*、^、|/+、括号，优先级为非、与、异或、或。随机数使用可重复的 xorshift32 种子，服务教学验证，不用于密码学。
- 保存使用自有 `.logic.json`；可[交换经典 Logisim `.circ`](CIRC_IMPORT_CN.md)，不支持 JAR 扩展库、evolution 工程或专业 HDL 仿真。旧 `.eda.json` 不属于数字工程格式，打开时提示不支持。
- 数字工程需显式保存；尚未提供自动恢复和运行状态断点持久化。
