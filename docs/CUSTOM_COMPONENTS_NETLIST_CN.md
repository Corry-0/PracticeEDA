# 工程师自定义元件与网表导出

## 创建与复用

1. 打开“项目 → 新建自定义元件”，填写元件名称。
2. 输入和输出分开填写，每行采用 `名称:位宽`，例如输入 `DATA:8`、`CLK:1`，输出 `Q:8`。接口名称不可重复，位宽为 1–32；输入或输出可单独留空，总接口数量为 1–64。
3. 创建后打开元件定义画布，自动放置命名接口。添加门、总线、寄存器、存储器或其他自定义元件并连线，实现所需功能。新建操作只生成接口，内部逻辑由工程师设计。
4. 在左上角切回 `main` 或其他调用电路，从左侧“自定义元件 / 子电路”库选择元件并放置。搜索框支持元件名称；双击实例进入该实例的实时运行视图，面包屑和上级按钮保留父电路状态。
5. 在右侧“属性 / 值”表格直接修改接口名称和位宽。名称变化保留原连接，因为连接使用稳定的接口 ID；位宽变更后应查看诊断并同步调整外部总线。
6. 在定义画布使用“项目 → 保存当前电路为元件”，生成 `.component.json`。已有电路也可以直接保存为元件，只需至少包含一个 Input 或 Output。`examples/half-adder.component.json` 可直接试用。
7. 其他工程通过“项目 → 导入自定义元件”读入。导入后进入放置模式，单击画布创建实例，Esc 取消放置；定义仍保留在库内。导入与放置分别支持撤销重做。

自定义元件与子电路使用同一个仿真模型，支持组合逻辑与时序逻辑。每个实例拥有独立的寄存器/RAM 状态。编辑定义会影响当前工程内的所有实例，并按既有结构编辑行为复位仿真。元件文件是快照，修改原工程不会自动修改已经导入其他工程的定义。

## 运行实例与定义编辑

实例运行视图使用原来的 `Simulator` 和完整路径，例如 `p12/p34/p56`；进入和返回不会调用 reset、重新展开或创建另一个运行器。寄存器、内存、键盘 FIFO、TTY 文本和内部独立时钟都属于各自的实例。选择 RAM/ROM 后可查看其真实运行内存；只读窗口与 PNG/网表导出均不能把运行值写回定义初值。

需要修改内部元件、接口、外观或参数时，明确选择“项目 → 编辑当前电路定义（暂停并复位）”。只读观察和结构修改有不同入口。定义编辑影响全部调用实例，因此必须复位；输入切换、实例导航和选择对象则保留运行态。内部 Input/Output 仍连接父电路，不能当作绕过父连接的独立输入源。

## 图形与元件外观

“工具”菜单提供直线（L）、曲线（B）、矩形（R）、椭圆（E）和圆（C）。电路模式下绘制的是当前电路的图形标注；切换到元件外观后，绘制的是当前定义的实例符号。绿色接口标记来自定义中的输入、输出引脚；通过“项目 → 自定义符号引脚布局”填写其相对中心的 X/Y，建议按 10 像素网格安排。绘图本身不会改变连线或逻辑功能。没有自定义外观时沿用默认矩形符号。

- 直线、矩形、椭圆、圆：按下并拖动，松开完成。圆始终保持等宽等高。按住 Shift 可将矩形约束为正方形、椭圆约束为圆、直线约束为水平/竖直/45 度。
- 曲线：先拖出起点、终点并松开，再移动鼠标调整二次曲线控制点，单击完成。Esc 或右键取消未完成图形；零尺寸操作不会创建对象。
- 按 S 选择图形，拖动移动；选中后拖动端点调整尺寸，曲线另有圆形控制点。支持 Shift 多选、框选、方向键移动、Ctrl+A、复制/剪切/粘贴、Delete、撤销和重做。
- 右侧属性表格的图形线宽范围为 1–20；“填充”适用于矩形、椭圆、圆。选中图形后修改会立即应用；未选中时作为下一次绘制的样式。
- 切回电路编辑继续内部连线，返回调用电路可见所有实例的外观更新。双击实例进入运行观察；编辑结构使用单独的定义编辑入口。图形外观本身不产生电气功能。
- 外观和电路标注随 `.logic.json`、`.component.json` 保存，并随嵌套元件导入及跨工程复制保留。PNG 导出当前编辑模式下的完整内容。旧版工程缺少图形字段时视为空列表。

可导入 `examples/drawn-half-adder.component.json` 试用带自定义外观的半加器。底层 `Circuit.shapes` 保存几何坐标、类型、线宽、填充及 `appearance` 层标记，仿真器和网表忽略图形。

接口坐标保存于 `Circuit.interfaceLayout`，键为定义内部的 Input/Output 稳定 ID。接口名称可改，ID 不变；旋转实例时端口坐标一起旋转。已有导线保留原端口 ID，因此随端点移动；跨工程导入、复制、封装时布局键必须与接口一起重映射。外观坐标不是信号状态，也不参与电气网络求值。

## 元件文件

外层标识为 `format: "PracticeEDA.component"`、`version: 1`，`project` 保存完整的数字工程结构，`project.main` 指定该元件的根定义。文件只包含根定义及其递归依赖，不包含无关电路。

导入先校验，再在候选工程上处理名称和 ID。已有定义不会覆盖，重名使用 `_import1`、`_import2` 等后缀；对象 ID、导线两端及嵌套实例端口 ID 一并重映射。未知版本、非法位宽、无效端点、递归引用、超过工程容量等错误会拒绝导入，原工程保持不变。工程数量上限仍为 128，文件上限仍为 32 MB。工程保存格式继续使用原有 `.logic.json` 第 1 版，旧示例可直接读取。

0.5 增量字段为元件 `rotation`、`params`、`bitGroups` 和定义 `interfaceLayout`。旧文件缺失这些字段时使用原默认行为；保留 version 1 不代表旧程序认识新增器件。需要继续编辑时应保留本程序工程；`.circ` 交换存在单独的行为与外观边界，见 [交换说明](CIRC_IMPORT_CN.md)。

## 导出网表

打开“文件 → 导出网表”，选择所需格式。导出范围是**当前打开的电路及其全部嵌套实例**；若需整个主电路，先切回 `main`。与当前电路无关的定义不会加入网表。

导出采用仿真器编译出的连接网络，因而同名节点连接、显式分支、层次接口连接和实例隔离遵循现有仿真语义。画面上的导线交叉不会凭空变成连接。导出不执行事件、不切换时钟、不改动输入值、寄存器、RAM、事件队列或工程历史。

### KiCad S-expression `.net`

采用 `(export (version "D") ...)` 形式，包含 `design`、`components`、`nets`。连接结构参考 [KiCad 官方网表文档](https://docs.kicad.org/6.0/en/eeschema/eeschema.html#netlist-formats)。

- 展开到基本逻辑元件，并以 `U1`、`U2` 等唯一引用标识元件；`InstancePath` 字段记录原层次实例路径，`Label` 保留元件显示名。
- 保留 `Width`、`InitialValue` 和 `MemoryData` 字段，后两者是工程初值，**不是正在运行的状态快照**。
- 总线按最低位从 0 开始展开，如 `Y[0]`–`Y[7]`；网络名为 `N1[0]` 等。单比特引脚保持 `Y`、`CLK` 等原名。
- 悬空引脚仍有单独网络，未连接输出不会被默默删除。文字标签不是电气元件。

这是逻辑连接交换文件：元件仍为虚拟 AND、Register、RAM 等，不包含实体芯片引脚号、PCB 封装或模拟器件模型；不是 SPICE 或 Verilog 仿真程序，不能直接作为可生产 PCB 的网表。已验证语法和连接对应关系。第三种“KiCad实体映射网表”另行生成真实引脚和配套板，实际外部加载与范围见 [PCB交换说明](PCB_EXCHANGE_CN.md)。

### 完整数字网表 `.net.json`

标识为 `format: "PracticeEDA.netlist"`、`version: 1`。

| 字段 | 含义 |
| --- | --- |
| `project` / `circuit` | 工程名称 / 当前导出根电路 |
| `components[].ref` / `path` | 网表唯一引用 / 原始实例层次路径 |
| `kind` / `label` / `width` | 元件类型 / 标签 / 数据位宽 |
| `value` / `data` | 工程初值 / 存储器初始化数组 |
| `rotation` / `params` / `bitGroups` | 四方向标识 / 可选整数属性 / 总线位映射 |
| `components[].pins[]` | 引脚 ID、方向、位宽和所属网络编号 |
| `nets[].id` / `name` / `width` | 网络编号、稳定生成名称和总线位宽 |
| `nets[].aliases[]` | 合并到此网络的原始元件端口、层次接口、节点和导线端点标识 |
| `nets[].labels[]` | 用户网络标签及其所属实例路径 |
| `nets[].pins[]` | 网络连接的基本元件引用和引脚 ID |

网络中所有已知引脚位宽必须一致，否则两种格式都会拒绝导出并提示修复。驱动冲突和悬空等问题仍显示在原诊断面板中，网表忠实记录连接，不将当前 E/X/Z 当成硬连线常量。相同工程多次导出内容确定，可用于版本比较。两种网表均为导出用途，重新编辑请保留 `.logic.json`。

网表描述的是静态导线拓扑与原语参数。晶体管和传输门在运行时动态联通两侧网络，文件中仍保留开关原语与 A/B 端连接，不把某一刻导通状态固化成永久短接。弱上/下拉的含义由 kind 决定；静态网表不是模拟电路求解结果。
