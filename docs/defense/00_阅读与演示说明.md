## 四人出场与收尾

- 第 02 页：A 介绍四人的主讲职责。
- 第 07 页：A → B；第 13 页：B → C；第 19 页：C → D。交接页同时显示已解决的问题、下一位职责和双方口头句。
- 第 24 页：D 回顾成果、现有边界与下一轮验收目标。
- 第 25 页：A、B、C、D 各说一句总结，由 D 邀请提问；四人按模块接答。

## 如何展示

1. 用 Edge 或 Chrome 打开 `ppt/index.html`；文件可直接离线使用，图片和动效代码已经内嵌，不依赖字体或图片 CDN。
2. 建议使用 16:9 投影，按 `F11` 全屏；左右方向键翻页，`Esc` 查看总览。
3. 点击右下角 **P / 演讲模式**，当前窗口显示备注、当前页、下一页与计时，并打开独立观众窗口。把观众窗口移动到投影屏。
4. 若浏览器阻止弹窗，允许此文件的弹窗后点“重新打开观众屏”；以演讲者窗口中的同步状态为准。
5. 讲稿已逐页内置。默认不自动翻页；计时和排练需点击按钮启动。每页计划时间只作提醒。
6. 普通展示模式的 `B` 可切换动态 / 静态；演讲者模式的 `B` 控制观众黑屏，快捷键作用依模式不同，完整说明见演讲者“设置”。

如浏览器限制本地文件的多窗口通信，可在仓库根目录用本机静态服务打开：

```powershell
python -m http.server 8765 --bind 127.0.0.1
```

随后访问 `http://127.0.0.1:8765/docs/defense/ppt/index.html`。服务仅用于本机展示，结束后在启动它的终端按 Ctrl+C。

## 改稿与源码核对

- HTML 是网页演示文件，不是 `.pptx`。它保留技能模板提供的翻页、演讲者、备注、计时和观众同步功能。
- 页面中的 C++ 代码是可选中的文字，不是图片。每段附文件名和行号；它们来自核对当日的源码，后续修改源码后应重新核对行号。
- 源码详细文档中的相对链接，在仓库原有 `docs/defense/` 位置可用。若只转发本目录，讲解内容仍完整，但跳转仓库源码需同时提供源码仓库。
- 两张电路图来自实际 GUI 导出，原图保存在 `ppt/images/`；未重绘或虚构 UI。
- HTML、Markdown 和 `slides.json` 是交付快照，手工修改其中之一不会自动更新另两份。正式改稿请同步页面标题、逐页讲稿和 `SPEAKER_NOTES`。
- 演讲者窗口内编辑的备注保存在当前浏览器本地存储，不会自动写回 HTML；正式稿应更新文件后再分发。

## 事实与分工边界

四人分工是建议的答辩责任分配，不是历史代码作者认定；真实姓名和贡献由小组据实填写。方案比较是有依据的设计复盘，不暗示所有方案均实现或做过性能测试。

迭代叙事基于旧原型提交、日期文档和当前代码。无法由记录确定的阶段按能力依赖组织，不编造开发排期。Logisim 支持范围以 [导入说明](../LOGISIM_IMPORT_CN.md) 为准；占位保留不表示原电路完整等价。
