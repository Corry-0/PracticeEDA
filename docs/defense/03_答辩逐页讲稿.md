## 10｜交叉是几何，连接是端点（B，69 秒）

**代码 / 证据**：`include/LogicSupport.h::Endpoint；DigitalEditor.cpp::endpointAt/route/cancel`。

**操作提示**：指向本页关键机制；不要逐字念代码。

**口述正文与交接提示**：

## 16｜bool 不足以解释一根导线（C，39 秒）

**讲解目的**：解释每位信号与错误状态。

**代码 / 证据**：`include/Digital.h::Signal；Digital.cpp::evaluate/resolve`。

**操作提示**：指向本页关键机制；不要逐字念代码。

**口述正文与交接提示**：

单一布尔值无法表达未连接、三态关闭和多驱动冲突。当前 Signal 用 value、known、z、error 四个位掩码描述一到三十二位总线。

零和一是已知值；X 是未知；Z 是高阻；E 单独表示错误或冲突。第六格说明掩码结构，不是第六种逻辑状态。这样一条总线里可以有些位确定、有些位未知。

门运算也按位推导。例如与门某一位已经有确定零，另一个输入未知时仍能确定输出零；不能简单地把所有含 X 的输入一律算成 X，更不能把它当零。

## 17｜同一时刻，先一起算，再一起发布（C，78 秒）

**讲解目的**：用两级寄存器解释同时事件语义。

**代码 / 证据**：`src/Digital.cpp::Simulator::Impl::step`。

**操作提示**：先指左循环，再指右循环；口述 R1/R2 的前后值。

**口述正文与交接提示**：

这是仿真里最值得关注的两段循环。左边对整个 batch 求值，输出先写入各节点缓存，同时收集受影响的网络。右边等整批求值结束后，才解析网络并发布新信号，再把下游排到下一逻辑时刻。

为什么不能计算一个就立即发布？假设 R1 的输出接 R2 的输入，两个寄存器共享时钟。上升沿前 R1 为一、R2 为零，R1 的输入为零。正确采样后 R1 应为零、R2 应为一。

如果先更新 R1 并立即改网络，后算的 R2 可能读到新零，结果就依赖元件排列。当前 input 读取旧的 net.signal，整批求值后再发布，因此 R2 仍能采到旧一。

queue 中的时刻是逻辑时间，默认传播间隔一，不代表纳秒。settle 还有批次数预算，防止振荡或传播过长让界面一直等待。

## 21｜外部电路：选择有边界的兼容（D，48 秒）

**操作提示**：指向本页关键机制；不要逐字念代码。

**口述正文与交接提示**：

对 circ 文件有三种策略：完整复现 外部电路、遇到未知组件就拒绝，或者支持一个清楚的子集。完整兼容成本很高，因为元件端口、方向、使能和存储语义都有差异；全部拒绝又浪费文件中本来可以转换的部分。

## 22｜转换到原生模型，诊断随工程留下（D，72 秒）

**操作提示**：指向 Text 字段和最后一行校验；需要现场演示时使用预留两分钟。

**口述正文与交接提示**：

第二段只有一行，却体现边界选择：生成 Project 后再经过 serialize 和 deserialize，最终用原生校验接受它。代价是多一次编解码，但避免两套校验规则逐渐分叉。

## 追问准备：先回答结论，再给源码证据

### Q01：为什么不用 Qt 或 Web？（A 主答）

当前继承 C++ / wxWidgets 工程，沿用已有事件和构建能减少重写。不是证明其他框架不适合；如要求浏览器协作，应重新评估。

### Q02：这个项目难点究竟是什么？（A/C 主答）

连接身份、时序语义和边界转换的一致性。例如几何相交不等于接通，同沿寄存器不能按遍历顺序采样，导入不能只匹配名字。

### Q03：为什么不用坐标保存连接？（B 主答）

坐标属于显示，移动会改变；稳定对象与端口 ID 可以在移动、保存和重命名后保留电气身份。

### Q04：快照撤销会不会很慢？（B 主答）

会有复制和序列化比较开销，所以仅保留有限历史。当前面向教学规模；大工程要先测量再选差量日志。

### Q05：同一批事件是多线程同时算吗？（C 主答）

不是。单线程依次计算，但都读取旧网络信号，全部完成后再发布网络，得到同时采样的语义。

### Q06：为什么不用拓扑排序？（C 主答）

它适合无环组合网络；本项目还包含状态、反馈和诊断，事件队列更容易统一。可将组合子图优化作为后续任务。

### Q07：电路有环就一定错误吗？（C 主答）

不一定。时序反馈是正常结构，某些组合反馈可收敛。settle 的预算只用于防止长时间不结束，超限不等于形式化证明振荡。

### Q08：Z、X、E 有什么区别？（C 主答）

Z 是高阻，X 是未知，E 是冲突或非法状态。多个确定但相反的驱动不能随便取其中一个值。

### Q09：保存文件为什么没有当前 RAM 内容？（A/C 主答）

Part.data 是复位初值，运行内存归仿真器。若要保存运行现场，应设计独立状态快照而非改变字段含义。

### Q10：为什么不能完整兼容 外部电路？（D 主答）

元件配置、端口几何和时序语义并非都能等价映射。当前先支持明确子集，拒绝不等价映射并保留说明。

### Q11：不支持元件保留后，仿真仍正确吗？（D 主答）

只能保证已映射部分按当前模型执行，不能保证整个原电路功能等价；占位不参与原器件行为，用户需查看诊断并修补。

### Q12：为什么将导入错误存为 Text？（D 主答）

它复用现有保存、编辑、撤销和诊断定位，不更改原生格式。代价是没有完整原始组件结构，无法无损往返。

### Q13：为什么 importComponent 连 pin 都要重映射？（D 主答）

子电路实例端口 ID 来自定义内部 Input/Output 的对象 ID，导入更换这些对象身份后，端点 pin 也必须改变。

### Q14：测试数量是不是覆盖率？（D 主答）

不是。1375 是三组程序运行时检查之和，49 是独立网表对比组数，4 是 CTest 目标数。尚未据此报告代码覆盖率。

### Q15：KiCad 网表是否可以直接生产 PCB？（D 主答）

不可以。当前表达逻辑连接，没有真实芯片封装和制造约束，也没有完成外部 PCB 工具验收。

### Q16：如何证明你们有迭代而不是只做了最终版本？（A 主答）

展示旧提交中的绘图和路径探索、日期验证报告与当前功能差异。对缺少逐阶段提交的现代能力明确按依赖关系复盘，不编造时间和归属。
