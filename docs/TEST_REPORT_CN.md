## 自动化检查

- 原数字逻辑回归：173 项，覆盖门、总线、时钟、触发器、存储器、层次实例、四态信号、粘贴和异常文件。
- 自定义元件与网表回归：135 项，覆盖接口创建、无效输入、同名定义、嵌套依赖、对象和端口 ID 重映射、导入原子性、撤销重做、工程往返保存、Unicode 路径、递归拒绝和容量上限。
- 实例与状态检查：两份自定义 8 位寄存器实例保留独立值；在存在待处理事件时导出，时间、队列、输出和追踪记录保持不变，随后继续时钟采样仍正确。
- 连接检查：层次接口、32 位总线、同名标签、实例内标签作用域、悬空引脚、图形重叠不连接、全部内置元件引脚，以及位宽冲突拒绝导出。
- 独立 Python 解析：49 组网表文件，解析实际生成的 `.net` 文件，逐项比对 `.net.json` 中的引用、标签、初值、存储器数据和每一位引脚所属网络，检查括号、字符串转义和编号唯一性。
- GUI 集成：保留原启动、图标、绘图、拖拽、布线、属性、剪贴板、撤销、保存与加载检查；新增真实自定义元件对话框、混合位宽接口、导入后放置、半加器真值表、网表导出和状态保护检查。

## 复现

```powershell
.\scripts\build.ps1 -Configuration Debug -GuiTest
.\scripts\build.ps1 -Configuration Release -GuiTest -Package
```

`ctest` 注册 `digital_logic_tests`、`component_netlist_tests`。安装 Python 3 时还自动注册 `netlist_format_tests`；该验证器只使用标准库。

核心测试产物位于 `build/qa-features/Debug/` 和 `build/qa-features/Release/`，GUI 成功标志和图片位于 `build/qa-debug/`、`build/qa-release/`。`custom-half-adder.png` 展示导入元件与外部端口连接；对应 `.net` 和 `.net.json` 可直接检查。

## 验证边界

检查针对上述功能和回归范围，不是对所有未来输入“绝无 bug”的数学证明。`.net` 已执行独立语法解析与连接比对，未执行外部 KiCad PCB 导入测试；逻辑元件没有物理封装，不能直接当作制造网表。GUI 自动化覆盖元件编辑器和导出逻辑，系统原生文件选择器的人工点击未自动化。
